它到底做什么

① 判读

意图、情绪分布、着急程度、要不要回、有没有风险、建议姿态 —— 一次请求 8 个问题问完 Jev。

② 攻略度

给「当前关系进展」打一个 0~100% 的分，并显示与上次的差值：65%（↑ +8）。看趋势比看单次数值有意义。

③ 三条回复

不是建议，是成品：稳妥（不犯错）、推进（往前一步）、有趣（轻松幽默），另外还有 撒娇 / 冷淡 / 正经 / 长辈 可以按关系自己勾。点一下就复制。

④ 记得住

每个联系人一份本地记忆（摘要 + 关键事实 + 历次评分）。所以它知道「她养了只叫团子的猫」。

怎么用

  1. 装 APK（不需要 root，跟插件版不一样），打开 App 开启无障碍服务
  2. 填两个密钥：Jev 密钥（判读）+ 聊天模型密钥（写文案，任何 OpenAI 兼容端点都行）
  3. 微信里打开聊天 → 下拉栏磁贴「攻略一下」/ 通知栏「判读一下」/ 无障碍按钮
  4. 看结果页，点文案复制，粘贴发出去

国产 ROM 记得给 App 开自启动/后台白名单，否则无障碍服务会被省电策略杀掉。

和同门的分工

项目形态干什么要 root
JevIntentFkWeChat 插件长按消息，弹 3 条判读提示要
JevBystander独立 App读屏判读，弹 3 条提示不要
JevGuide独立 App判读 + 攻略度 + 3 条成品回复 + 长期记忆不要

隐私

密钥、联系人表、日志在本机 SharedPreferences；每个联系人的记忆在本机 filesDir/memory/，卸载即消失。没有云端、没有统计、运行期零第三方依赖（连 OkHttp/Gson 都没引）。

只把当前会话相关内容发给两个接口：Jev（判读/攻略度）和你自己配的聊天模型（文案）。不修改、不发送任何消息，也不截屏。

已知限制

· 只能读屏幕上已显示的文字：长消息折叠部分、图片/语音/文件、群聊里的多人归属都读不到
· 必须精确匹配包名 com.tencent.mm，微信分身/克隆版读不到
· 攻略度是模型判断不是测量，同段对话换一次调用可能差 ±10%
· 文案是草稿，发出去前自己过一眼
